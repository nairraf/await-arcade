Install Await Arcade

Last updated: 12 November 2026

The beta-2 release installer is the normal path. Antigravity’s sidecar SDK is currently macOS-first; the policies remain drafts for review.

What you need

  • macOS or Linux (Antigravity’s sidecar SDK is currently macOS-first).
  • OpenCode Desktop and/or Antigravity.
  • Node.js 22 or newer. The source path also needs npm, Git, and python3.
  • A GitHub account for ranked play. Guest play works without one.

Release install

Download the beta-2 tarball and checksum from the GitHub Releases page, then: 

shasum -a 256 -c await-arcade-beta-2.tar.gz.sha256
tar -xzf await-arcade-beta-2.tar.gz
node await-arcade-beta-2/install.mjs --verify

The installer installs both hosts, merges the Antigravity config, preserves existing auth/state, and writes https://api.awaitarcade.com as the API URL. Use --opencode-only or --antigravity-only for one host, --home <dir> for a throwaway install, or --dry-run to preview.

From source

For contributors who want to build the hosts from the checkout:

git clone https://github.com/nairraf/await-arcade.git
cd await-arcade
npm install
npm run check
npm run build:hosts
AWAIT_ARCADE_API_URL=https://api.awaitarcade.com \
  ./scripts/install-hosts.sh

The source installer symlinks the packages into place. The release installer copies self-contained files instead.

Open the arcade

  • OpenCode: reload the app or restart the OpenCode service, then open the Await Arcade tab.
  • Antigravity: open the Await Arcade auxiliary pane. If it was already open, close and reopen it after rebuilding.

Sign in

Open the account panel and choose Sign in. GitHub Device Flow shows a short code; enter it at github.com/login/device. Each host keeps its own session, and both resolve to the same player.

Guest play stays local. Sign in to submit replay-verified runs, appear on the shared boards, play the daily challenge, and earn arcade XP.

Troubleshooting

  • The pane shows JavaScript as text: rebuild with npm run build:hosts, then close and reopen the Antigravity pane.
  • Sign-in expired: open the account panel, sign out, and sign in again.
  • API offline: play locally as a guest. Queued ranked submissions retry without double-submitting.
  • Old scores after an update: game versions can invalidate old replays; local bests reset on a version bump.

Clean uninstall

Quit OpenCode and close the Antigravity pane first. From the extracted release folder: 

node await-arcade-beta-2/install.mjs --uninstall --yes

This removes the OpenCode plugin, Antigravity sidecar, Antigravity config entry and project, local auth, queue, and sidecar data. It does not delete your GitHub account, the host apps, or the source repository.

To keep local auth and settings for a reinstall, add --keep-data. To remove only one host, add --opencode-only or --antigravity-only.

If you no longer have the release folder, redownload the beta tarball and run the same command. Manual fallback: remove ~/.config/opencode/plugins/await-arcade and ~/.gemini/config/sidecars/await-arcade, then remove the sidecars.await-arcade entry from ~/.gemini/config/config.json.
